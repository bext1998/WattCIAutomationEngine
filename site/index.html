WHAT WATT GUARANTEES

小而明確的執行邊界。

依序執行

Step 按 pipeline 定義的順序執行；失敗時立即停止，讓結果容易判讀。

本機優先

Watt 本身是單一 watt.exe，不需要 Node.js、Python 或額外 runtime；pipeline 執行的工具仍由專案環境提供。

可供機器使用

通過載入與靜態驗證的 watt run 會盡力寫出 JSON result，並用固定 exit code 區分結果類型。
